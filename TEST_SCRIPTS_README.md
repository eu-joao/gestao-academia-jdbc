# Scripts para Teste de Execução

## Para Linux/Mac:
```bash
chmod +x run_simple.sh
./run_simple.sh
```

## Para Windows:
```cmd
run_test.bat
```

## Resultado:
A saída completa (incluindo erros) será salva no arquivo `execution_output.txt` na raiz do projeto.

Isso ajudará a diagnosticar problemas com a execução do `MainAlunoSave`.
